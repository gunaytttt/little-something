# Little Something

A self-directed product case study by Gunay: a way to give money as a gift you design yourself, with a photo, a note and a reveal moment.

Open the case study: `index.html` (published with GitHub Pages).

- `index.html`: the case study
- `docs/`: the working documents behind it (PRD, user stories, business model, interviews, metrics notes)
- `walkthrough.mp4`, `poster.jpg`: the 90 second product walkthrough

Designed and prototyped, not launched. Payments in the prototype are mocked; no real money moves.
